01 · Princípios

Cinco regras para decidir sem reunião

01

Evoluir, não trocar

Fundo marinho, magenta e amarelo continuam. A IA entra nos detalhes, não numa ruptura.

02

Clicável parece clicável

Se leva a algum lugar, reage: brilho, elevação, afundar no clique. Se não leva, fica quieto.

03

Tecnologia com calma

Glow, grade e rede neural em doses pequenas. Se o efeito chama atenção para si, está demais.

04

Clareza antes de efeito

O dono da empresa entende em 5 segundos. Contraste AA, uma ação principal por tela.

05

Rápido como o nome

Animações de até 600 ms, nada bloqueia a leitura e "reduzir movimento" é sempre respeitado.

Entra rápido, não atrapalha

Toda a entrada da página termina em menos de 1 s. O texto é legível desde o primeiro quadro (sem tela de carregamento).

hooks/use-reveal.ts
export function useReveal() {
  useEffect(() => {
    if (matchMedia('(prefers-reduced-motion: reduce)').matches) return;
    const els = document.querySelectorAll('[data-reveal]');
    const io = new IntersectionObserver((entries) => {
      entries.forEach((e) => {
        if (!e.isIntersecting) return;
        e.target.classList.add('animate-fade-up');
        io.unobserve(e.target);
      });
    }, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
    els.forEach((el, i) => {
      (el as HTMLElement).style.animationDelay = `${(i % 6) * 70}ms`;
      el.classList.add('opacity-0');   // só esconde se o JS rodou
      io.observe(el);
    });
    return () => io.disconnect();
  }, []);
}

Foco visível

Anel amarelo de 2px com 2px de folga (ring-ring ring-offset-2) em todo botão, link e card clicável. Só aparece com teclado (focus-visible). Nunca remover outline sem substituto. Aperte Tab nesta página para ver.

Movimento reduzido

Com prefers-reduced-motion: texto aparece completo e parado, sem digitação; sem fade-up; borda viva e rede neural ficam estáticas; hover mantém cor e glow, sem deslocamento. Teste pelo Tweak "Simular movimento reduzido".

Também

Alvos de toque ≥ 44px. Texto "digitado" usa aria-live="polite" e o conteúdo completo em aria-label. lang="pt-BR | en | de" no html ao trocar idioma. Estrelas com aria-label "5 de 5".
